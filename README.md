# 🍝 Savorella

Savorella é um site fictício de restaurante desenvolvido como projeto de portfólio, com o objetivo de demonstrar minhas habilidades em desenvolvimento web front-end, organização de layout, estilização responsiva e estruturação de páginas modernas.

## 🚀 Objetivo do Projeto

Este projeto foi criado para praticar e demonstrar conhecimentos em:

* Estruturação semântica com **HTML**
* Estilização moderna e responsiva com **CSS**
* Interatividade com **JavaScript**
* Organização de layout voltada para experiência do usuário
* Boas práticas de desenvolvimento para projetos web

## 🖥️ Funcionalidades

* Página inicial com apresentação do restaurante
* Seção de cardápio com pratos e descrições
* Área de destaque (cover) com chamada para reserva de mesa
* Layout responsivo para diferentes tamanhos de tela

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## 📂 Como visualizar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/gustavohenriquehg6/savorella.git
   ```
   link do site https://savorella.com.br/
2. Abra o arquivo `index.html` no navegador.
